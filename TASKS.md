## Root Cause Analysis

Two screen paths display paper cards:
1. **Exams & Grades screen** (`lib/ui/screens/school_dashboard/exams/exams_grades_screen.dart`) — uses `_PaperSlotCard` (mobile) and `_PaperSlotBox` / `_PaperEmptyCell` (desktop cross-table cells).
2. **Academics → Grade → Exams tab** (`lib/ui/screens/school_dashboard/academics/exam_detail_page.dart`) — uses `_PaperTimetableCard` (mobile) and `_buildCell` inside `_PapersCrossTable` (desktop).

### Diagnosed bugs that cause misalignment / different card sizes

| # | Bug | Location | Root cause |
|---|---|---|---|
| A | Mobile cards have different heights per status | `_PaperSlotCard.build` | The invigilator text row is wrapped in `if (invigilatorName.isNotEmpty)` — cards without an invigilator are shorter. |
| B | Subject name can wrap to 2 lines on mobile | `_PaperSlotCard.build` | Subject `Text` has no `Expanded` wrapper, no `maxLines` — long names push card height up. |
| C | Right-side column not vertically centered | `_PaperSlotCard.build` | Right `Column` (chip + chevron) has no `mainAxisAlignment` → defaults to `start`, so content pins to top leaving empty gap below on taller cards. |
| D | Status chip width varies by status text | `_StatusChip.build` | "Pending" (7 chars) vs "In Progress" (11 chars) vs "Done" (4 chars) vs "Marked" (6 chars) — no `minWidth` constraint on the chip `Container`. |
| E | Desktop grid cells have different heights | `_PaperSlotBox.build` | Uses `BoxConstraints(minHeight: 56)` and `maxLines: 2` on subject — a 2-line subject makes its cell taller than single-line cells in the same column. |
| F | Desktop empty cells may not match occupied cells | `_PaperEmptyCell.build` | Also uses `BoxConstraints(minHeight: 56)` — if occupied cells grow past 56, empty cells stay at 56 and look shorter. |
| G | `_PaperTimetableCard` status chip varies in width | `_PaperStatusChip.build` in `exam_detail_page.dart` | Same variable-width issue as bug D. |
| H | `_PaperTimetableCard` subject can wrap to 2 lines | `_PaperTimetableCard.build` | `maxLines: 2` — inconsistent card heights across the mobile list. |
| I | Desktop `_PapersCrossTable` cells not fixed height | `_buildCell` + empty cells in `_PapersCrossTable` | `BoxConstraints(minHeight: 56)` and `maxLines: 2` on subject — same as bugs E+F. |
