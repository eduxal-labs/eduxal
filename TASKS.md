## Track A — School Dashboard Role Permissions UI Overhaul

### Problem Summary

The school dashboard's role management UI has two aesthetic gaps compared to the system dashboard:

1. **Role creation form** (`_RoleFormSheet` in `school_roles_screen.dart`): Only collects name + description. Permissions are saved as empty `'[]'` — the user must navigate to the detail screen after creation to add any permissions. The system dashboard's `CreateRoleSheet` (`create_role_sheet.dart`) includes a full inline permissions editor with expandable resource cards, Switch toggles, count chips, per-resource select-all, and a global select-all button.

2. **Role detail screen expanded permissions** (`_ExpandedPermissions` in `school_role_detail_screen.dart`): Uses a `Wrap` of 36×36 icon tiles — compact but less information-dense and less polished. The system dashboard's equivalent uses a vertical list of rows with icon + label + spacer + Switch toggle — a more traditional, spacious, and polished pattern that clearly communicates each action's name and state.

**Goal:** Replicate the system dashboard's permissions aesthetic on the school dashboard, in both the creation form and the detail screen.

### Data Model Note

The school dashboard uses the **typed bitmask model** (`Map<Resource, int>` with `Action` enum masks from `lib/models/permissions.dart`), while the system dashboard uses a legacy string-based model (`Map<String, bool>`). The school model is the correct one per AGENT.md §17a. All new code must use the typed `Resource`/`Action` enums and bitmask operations.

**Available helpers** (already defined as top-level functions in `school_role_detail_screen.dart`):
- `_parsePermissions(String? jsonStr) → Map<Resource, int>` — parses JSON → bitmask map
- `_serialisePermissions(Map<Resource, int> perms) → String` — bitmask map → JSON string
- `_countPermissions(Map<Resource, int> perms) → int` — total granted count via popcount
- `_popcount(int v) → int` — Hamming weight of a u16
- `_buildResourceGroups() → List<_ResourceGroup>` — 5 semantic groups (People, Academic, Finance, School Admin, System)
- `_kActionColors` / `_kActionIcons` — `Map<Action, Color>` / `Map<Action, IconData>` with 9 entries

**Available enums** (from `lib/models/permissions.dart`):
- `Resource` — 19 values, each with `.label` (String) and `.applicableActions` (List\<Action\>)
- `Action` — 9 values, each with `.label` (String), `.bit` (int), `.mask` (int = 1 << bit)

#### 4. Permission toggle methods

```dart
// Count of granted actions for a specific resource
int _resourceSelectedCount(models.Resource resource) {
  final mask = _permissions[resource] ?? 0;
  return _popcount(mask);
}

// Total applicable actions for a resource
int _resourceTotalCount(models.Resource resource) {
  return resource.applicableActions.length;
}

// Total selected across all resources
int get _totalSelectedCount {
  var count = 0;
  for (final mask in _permissions.values) count += _popcount(mask);
  return count;
}

// Total possible across all resources
int get _totalPermissionCount {
  var count = 0;
  for (final group in _resourceGroups) {
    for (final r in group.resources) count += r.applicableActions.length;
  }
  return count;
}

bool get _allSelected => _totalSelectedCount == _totalPermissionCount;

void _togglePermission(models.Resource resource, models.Action action) {
  setState(() {
    final current = _permissions[resource] ?? 0;
    _permissions[resource] = current ^ action.mask;
    if (_permissions[resource] == 0) _permissions.remove(resource);
  });
}

void _toggleResourceAll(models.Resource resource) {
  setState(() {
    final actions = resource.applicableActions;
    final current = _permissions[resource] ?? 0;
    final fullMask = actions.fold<int>(0, (m, a) => m | a.mask);
    if (current == fullMask) {
      _permissions.remove(resource);
    } else {
      _permissions[resource] = fullMask;
    }
  });
}

void _toggleSelectAll() {
  setState(() {
    if (_allSelected) {
      _permissions.clear();
    } else {
      for (final group in _resourceGroups) {
        for (final r in group.resources) {
          _permissions[r] = r.applicableActions.fold<int>(0, (m, a) => m | a.mask);
        }
      }
    }
  });
}

void _toggleExpand(models.Resource resource) {
  setState(() {
    if (!_expandedResources.add(resource)) _expandedResources.remove(resource);
  });
}
```

Add a local `_popcount`:
```dart
static int _popcount(int v) {
  var n = v & 0xFFFF;
  n = n - ((n >> 1) & 0x5555);
  n = (n & 0x3333) + ((n >> 2) & 0x3333);
  return (((n + (n >> 4)) & 0x0F0F) * 0x0101) & 0xFF;
}
```

Where `_serialisePerms` is:
```dart
String _serialisePerms() {
  final list = <Map<String, dynamic>>[];
  for (final entry in _permissions.entries) {
    if (entry.value == 0) continue;
    final actions = models.Action.values
        .where((a) => entry.value & a.mask != 0)
        .map((a) => a.name)
        .toList();
    if (actions.isNotEmpty) {
      list.add({'resource': entry.key.name, 'actions': actions});
    }
  }
  return jsonEncode(list);
}
```
