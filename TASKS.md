## Track A — Dark Mode Color Fix (surfaceContainerHigh / surfaceContainerLow)

### Problem Summary

The dark theme in `AppTheme.dark()` overrides 5 of the 7 Material 3 surface staircase slots with a custom cool blue-gray "slate" palette. Two slots — `surfaceContainerHigh` and `surfaceContainerLow` — are **not overridden** and fall back to Material 3's auto-generated values. With the indigo seed color (`#3F51B5`), the auto-generated values carry a warm purplish-brown tint (~hue 280°) that clashes with the cool slate palette (hue ~210–220°).

This is most visible on the **Roles/Permissions UI** (both dashboards), where `surfaceContainerHigh` is used for resource row backgrounds, assigned-user rows, and form card containers. The brownish tone is jarring.

## Track B — Mobile Sheet Keyboard Handling

### Problem Summary

After BUG-010, `showEduSheet` on mobile no longer wraps content in `EduSheet` — it passes `builder(ctx)` directly to `showModalBottomSheet`. This means **each sheet widget must be fully self-contained**: own `Container` with background + border radius, own drag handle, `SingleChildScrollView` for scrollable content, `viewInsets.bottom` padding for keyboard, and a `maxHeight` constraint.

Many school dashboard sheets and account sheets were **not audited** during the BUG-010 fix (which only covered system dashboard sheets). These sheets are missing one or more of the required properties, causing:
1. **Transparent background** — sheet content floats over the page with no visible container
2. **No drag handle** — no affordance to dismiss
3. **No scroll** — form content overflows when keyboard appears
4. **No viewInsets padding** — keyboard covers action buttons
5. **No maxHeight** — sheet can expand beyond screen bounds

### The Standard Pattern

Every sheet shown via `showEduSheet` on mobile must follow this structure:

```dart
Widget build(BuildContext context) {
  final cs = Theme.of(context).colorScheme;
  final isDark = cs.brightness == Brightness.dark;

  return Container(
    constraints: BoxConstraints(
      maxHeight: MediaQuery.sizeOf(context).height * 0.92,
    ),
    decoration: BoxDecoration(
      color: AppTheme.modalBg(isDark, cs),
      borderRadius: const BorderRadius.vertical(
        top: Radius.circular(AppTheme.kModalRadius),
      ),
    ),
    child: Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        // Drag handle
        Center(
          child: Container(
            margin: const EdgeInsets.only(top: 10, bottom: 6),
            width: 36, height: 4,
            decoration: BoxDecoration(
              color: cs.onSurfaceVariant.withValues(alpha: 0.28),
              borderRadius: BorderRadius.circular(2),
            ),
          ),
        ),
        // Header (title, close button, etc.)
        // ...
        // Scrollable body
        Flexible(
          child: SingleChildScrollView(
            padding: EdgeInsets.fromLTRB(
              20, 8, 20,
              MediaQuery.viewInsetsOf(context).bottom + 24,
            ),
            child: Form(/* ... */),
          ),
        ),
        // OR: fixed action buttons with viewInsets padding
        Padding(
          padding: EdgeInsets.fromLTRB(
            20, 8, 20,
            MediaQuery.viewInsetsOf(context).bottom + 24,
          ),
          child: /* action buttons */,
        ),
      ],
    ),
  );
}
```

## Track C — Role Permissions: Creation & Detail Page Fixes

### Problem Summary

Three separate bugs across the two dashboards:

1. **School dashboard role creation** (`_RoleFormSheet` in `school_roles_screen.dart`): Hardcodes `permissions: const Value('[]')` — no permissions editor in the form. Users must create the role, then navigate to the detail page to add permissions as a separate step.

2. **System dashboard role detail** (`_PermissionsTab` in `role_detail_screen.dart`): Only renders resources that **already have active permissions**. If a role has zero permissions, the tab shows a dead-end empty state with no way to add any. If all permissions for a resource are toggled off, that resource disappears permanently.

3. **School dashboard action toggle UI** (`_ExpandedPermissions` in `school_role_detail_screen.dart`): Uses a `Wrap` of 36×36 icon tiles. The user prefers the system dashboard's switch-row pattern (icon + label + Switch toggle) which is more informative and polished.

### Data Model Note

The school dashboard uses the **correct typed bitmask model** (`Map<Resource, int>` from `lib/models/permissions.dart`). The system dashboard uses a **legacy string-based model** (`Map<String, bool>` with keys like `"users.read"`). The system dashboard also defines resources that don't exist in the `Resource` enum (e.g. `terms`, `enrollments`, `mastery`, `classTeachers`).

**All fixes in this track use the typed model.** The system dashboard will be migrated from its legacy string model to the typed model as part of Task C3.

**Available helpers** (from `school_role_detail_screen.dart`):
- `_parsePermissions(String? jsonStr) → Map<Resource, int>` — parses JSON → bitmask map

- `_countPermissions(Map<Resource, int> perms) → int` — total granted count
- `_popcount(int v) → int` — Hamming weight
- `_buildResourceGroups() → List<_ResourceGroup>` — 5 semantic groups
- `_kActionColors` / `_kActionIcons` — `Map<Action, Color>` / `Map<Action, IconData>`

    _permissions[r] = current ^ a.mask;

void _toggleResourceAll(Resource r) {
  setState(() {
    final allMask = r.applicableActions.fold<int>(0, (m, a) => m | a.mask);
    final current = _permissions[r] ?? 0;
    if (current == allMask) {
      _permissions.remove(r);
    } else {
      _permissions[r] = allMask;
    }
  });
}

void _toggleSelectAll() {
  setState(() {
    final allPerms = <Resource, int>{};
    for (final g in _resourceGroups) {
      for (final r in g.resources) {
        allPerms[r] = r.applicableActions.fold<int>(0, (m, a) => m | a.mask);
      }
    }
    final totalPossible = allPerms.values.fold<int>(0, (s, v) => s + _popcount(v));
    final totalCurrent = _permissions.values.fold<int>(0, (s, v) => s + _popcount(v));
    if (totalCurrent == totalPossible) {
      _permissions.clear();
    } else {
      _permissions.addAll(allPerms);
    }
  });
}
